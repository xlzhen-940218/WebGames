# WebGames

一个简单的网页小游戏集合，包含若干基于 HTML/CSS/JavaScript 的轻量级游戏，适合在本地或静态主机上直接运行和学习。项目内部分文件可能由 AI 辅助生成并由作者整理。

**项目结构（简要）**
- `index.html`: 项目主页，入口页面。
- `css/`: 存放样式文件（例如 `style.css`）。
- `js/`: 存放脚本文件（例如 `script.js`）。
- `games/`: 游戏页面目录。
  - `games/tuixiangzi.html`: 推箱子小游戏。
  - `games/wuziqi.html`: 五子棋小游戏。
  - `games/tanchishe.html`: 贪吃蛇小游戏。
  - `games/eluosifangkuai.html`: 俄罗斯方块小游戏。
  - `games/pintu.html`: 美少女拼图小游戏。
  - `games/ersilingba.html`: 2048 小游戏。
  - `games/dazhuankuai.html`: 打砖块小游戏。
  - `games/shuxue.html`: 趣味数学大冒险（加减乘除冲关）。
- `images/`: 游戏使用的图片与矢量封面资源目录。
- `LICENSE`: 许可证文件（默认 MIT 或仓库内所示）。
- `README.md`: 本文件，项目说明。

**如何在本地运行/预览**
- 直接打开：在文件管理器中双击 `index.html`，或在浏览器中使用 `file://` 协议打开。
- 建议使用静态服务器（避免某些浏览器对本地文件的限制）：
	- 使用 Python 3（在项目根目录运行）：
		```bash
		python3 -m http.server 8000
		```
		然后在浏览器访问 `http://localhost:8000/`。
	- 或在 VS Code 中安装并启用 `Live Server` 插件，点击 `Go Live` 即可预览。

**已包含的游戏（简述）**
- **推箱子**（`games/tuixiangzi.html`）：经典推箱子玩法，使用键盘控制角色移动并推箱子到目标位置。
- **五子棋**（`games/wuziqi.html`）：棋盘落子、胜负判定的简单实现，适合学习和本地对弈。
- **贪吃蛇**（`games/tanchishe.html`）：玩家控制一条移动的蛇去吃场景中出现的食物。每吃到一个食物蛇身会变长并增加得分；蛇不能撞到自己的身体或地图边界，否则游戏结束。支持方向键控制与移动端适配。
- **俄罗斯方块**（`games/eluosifangkuai.html`）：由不同形状的方块从顶部连续下落，玩家可以左右移动并旋转方块以合理放置并消除得分，随时间加快下落速度提升挑战性。
- **美少女拼图**（`games/pintu.html`）：经典图块滑动拼图玩法，将打乱的拼图碎片逐步复原。
- **2048**（`games/ersilingba.html`）：通过方向键、WASD 或手机滑动合并相同数字，合成 2048 后还可以继续挑战更高分，并支持撤销一步与最高分保存。
- **打砖块**（`games/dazhuankuai.html`）：拖动挡板反弹小球击碎全部砖块即可过关，清空后自动进入下一关且球速提升；共有 3 条生命，支持手机触摸拖动、鼠标与 ← → 键控制，并保存最高分。
- **趣味数学大冒险**（`games/shuxue.html`）：卡通风格加减乘除极速心算冲关游戏。支持加法、减法、乘法、除法及四则混合挑战；拥有简单（10s）、普通（5s）、高危（3s）三档思考时间难度；题目难度平滑递进（个位数 5 题 ➔ 两位数 1~至9~ 阶梯 20 题 ➔ 三位数 1~~至9~~ 阶梯 50 题，共 75 关）；搭载独立音量滑轨调节（默认 30%）与纯前端 Web Audio 自适应多声部背景音乐和音效，竖屏全屏、横屏留白，全部通关触发完美通关彩带盛典。
